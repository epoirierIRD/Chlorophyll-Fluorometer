# Arduino Model
This project is designed to work with any Arduino Uno board compatible with the ATmega328 microcontroller or similar.

# Required Libraries
The following Arduino libraries are required to compile and run this project:

1. Wire.h
   - Included with Arduino IDE
   - Used for I2C communication.

2. U8glib.h
   - Available via Arduino Library Manager is the header file for the Universal 8bit Graphics Library (U8glib),
    a popular Arduino library designed for driving monochrome OLED and LCD displays.

3. SPI.h
   The SPI library allows you to communicate with SPI devices, with the Arduino board as the controller device. This library is
   bundled with every Arduino platform (avr, megaavr, mbed, samd, sam, arc32), so you do not need to install it separately.

4. SD.h
   - Available via Arduino Library Manager
   - The SD library allows for reading from and writing to SD cards, eg on the Arduino Ethernet Shield. 
   It is built on sdfatlib by William Greiman.

# Installation Instructions
To install the required libraries:
1. Open the Arduino IDE.
2. Go to Sketch > Include Library > Manage Libraries.
3. Search for each library by name and install it.

# Additional Setup
Ensure that your I2C devices (ADS1115 and SSD1306) are correctly connected to the Arduino I2C pins (A4 for SDA and A5 for SCL).
